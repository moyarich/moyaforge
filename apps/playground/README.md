# MoyaForge playground

Explore MoyaForge's documentation, interactive examples and UI components in the [live playground](https://moyarich.github.io/moyaforge/).

To create your own playground, use Node.js 24.11+ and npm:

```sh
npx @moyarich/moyaforge-cli@latest init --template playground --search
npm run dev
```

See the [CLI guide](../../packages/moyaforge-cli/README.md) and [component gallery](../../packages/moyaforge-ui/docs/page.mdx).

To run or contribute to this repository's private playground, see the [Development guide](../../docs/04-development/page.mdx).
