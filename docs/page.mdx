# Getting started

MoyaForge creates React/Vite/MDX documentation sites with editable UI components. Your documentation and generated application files belong to your own repository.

## Create a documentation site

In the directory where you want the application:

```sh
npx @moyarich/moyaforge-cli@latest create
npm run dev
```

The CLI generates an application, starter pages under `docs/`, and a `package.json`. It installs the `docs-shell` and `code-group` components from the MoyaForge registry into `src/components/ui/`, along with their required source files.

To choose an alternative starter:

```sh
# Documentation with an interactive playground route
npx @moyarich/moyaforge-cli@latest create --template hybrid

# Use the published MoyaForge package where applicable
npx @moyarich/moyaforge-cli@latest create --mode package

# Add SQLite-backed documentation search
npx @moyarich/moyaforge-cli@latest create --search
```

Use `--template existing` to generate an isolated `moyaforge/` application within an existing React project, with `docs:*` scripts rather than replacing the host's scripts.

Use `--no-install` to skip npm installation, `--dry-run` to preview changes, and `--overwrite` only when you intend to replace existing generated files.

## Add a component

You can install additional editable components in an existing project:

```sh
npx @moyarich/moyaforge-cli@latest init
npx @moyarich/moyaforge-cli@latest list
npx @moyarich/moyaforge-cli@latest add code-block
```

`init` creates only the component registry configuration. `create` generates the documentation application. Installed components import their own CSS.

## Create your first page

Edit `docs/page.mdx`. Frontmatter controls page metadata, while headings provide anchors for navigation.

```md
---
title: Welcome
label: Introduction
order: 1
---

# Welcome

Your documentation starts here.

## Your first guide

Write Markdown or use React components in MDX.
```

## How the generated app works

The starter uses React Router's `HashRouter` for static hosting, the `virtual:moyaforge-mdx/metadata` and `virtual:moyaforge-mdx/lazy-registry` modules for page discovery and loading, and the registry-installed `DocsShell` for layout.

The `--search` option additionally installs the existing `Search` UI component and configures the independent `@moyarich/moyaforge-search-sqlite` adapter. The starter's `SearchPanel` connects the search client to documentation routes; it does not duplicate the search input UI.

For generated-file details, see the [CLI guide](../packages/moyaforge-cli/README.md). Continue with [routing](./routing/page.mdx), [MDX](./mdx/page.mdx), [search](./search/page.mdx), and [examples](./examples/page.mdx).
