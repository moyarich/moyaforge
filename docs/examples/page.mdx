# Examples

These are repository-owned examples. The playground renders these documents using the MoyaForge MDX registry.

## Browse live component examples

- [Code Block](../components/code-block) — rendered code, copy action, and highlighted MDX fences.

Each component page is part of the repository-owned MDX content registry and opens directly in the playground.

## Install

```sh
npm install @moyarich/moyaforge @moyarich/moyaforge-mdx
```

## Render reusable UI

```tsx
// CodeGroup and CodeTab are installed from the MoyaForge component registry.
import { CodeGroup, CodeTab } from "@/components/ui/code-group";

export function Example() {
  return (
    <CodeGroup>
      <CodeTab label="npm">
        <pre>npm install @moyarich/moyaforge</pre>
      </CodeTab>
      <CodeTab label="pnpm">
        <pre>pnpm add @moyarich/moyaforge</pre>
      </CodeTab>
    </CodeGroup>
  );
}
```

## Compile repository-owned MDX

```js
import { createMdxOptions } from "@moyarich/moyaforge-mdx";
import { mdxRegistryPlugin } from "@moyarich/moyaforge-mdx/vite";

export default {
  plugins: [
    mdxRegistryPlugin({ registry, root: process.cwd() }),
    { enforce: "pre", ...mdx(createMdxOptions()) },
  ],
};
```

## Add SQLite documentation search

Use `@moyarich/moyaforge-search-sqlite/vite` with the same registry object. The indexing adapter remains independent of the MoyaForge React package.

## Lucide React icons

Common icons are registered in the playground MDX provider. Use them directly with Lucide's `size`, `color`, and `strokeWidth` props.

<div
  style={{
    display: "flex",
    alignItems: "center",
    gap: "20px",
    padding: "20px 0",
  }}
>
  <BookOpen size={28} aria-label="Documentation" />
  <Camera size={28} aria-label="Camera" />
  <Code size={28} aria-label="Code" />
  <Check size={28} color="currentColor" aria-label="Complete" />
  <Settings size={28} aria-label="Settings" />
</div>

```mdx
<BookOpen size={28} aria-label="Documentation" />
<Camera size={28} strokeWidth={1.5} aria-label="Camera" />
<Check size={20} aria-hidden="true" />
```

Available without imports: `BookOpen`, `Camera`, `Check`, `ChevronRight`, `Code`, `ExternalLink`, `FileText`, `Info`, `SearchIcon`, `Settings`, and `TerminalIcon`.

For any other Lucide icon, import it at the top of your MDX file:

```mdx
import { Rocket } from "lucide-react";

<Rocket size={32} aria-label="Launch" />
```

Use `aria-hidden="true"` for decorative icons next to text. Give standalone meaningful icons an accessible label.
