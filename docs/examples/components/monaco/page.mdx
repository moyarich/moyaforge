# Monaco

Provide an editor adapter with a configurable editor renderer.

## Preview

<Demo>
  <Monaco files={[{name:"hello.tsx",value:"export const Hello = () => 'Hello';",language:"typescript"},{name:"styles.css",value:".hello { color: blue; }",language:"css"}]} renderEditor={({file,value,onChange}) => (<label style={{display:"grid",gap:8}}><strong>{file.name}</strong><textarea aria-label={file.name} value={value} onChange={(event)=>onChange(event.target.value)} rows={4} style={{width:"100%"}} /></label>)} />
</Demo>

## Usage

```tsx
import { Monaco } from "@moyarich/moyaforge";

<Monaco files={[{name:"index.ts",value:"console.log('Hello')"}]} renderEditor={({value,onChange}) => <textarea value={value} onChange={e=>onChange(e.target.value)} />} />
```
