## Monaco

Monaco is an editor _adapter_, not a bundled editor. Supply `renderEditor` to integrate your preferred implementation. This example uses a textarea so it works without loading the VS Code services.

<Demo>
  <Monaco
    files={[
      {
        name: "hello.tsx",
        value: "export default function Hello() { return 'Hello'; }",
        language: "typescript",
      },
      {
        name: "styles.css",
        value: ".hello { color: royalblue; }",
        language: "css",
      },
    ]}
    renderEditor={({ file, value, onChange }) => (
      <label style={{ display: "grid", gap: 8 }}>
        <strong>{file.name}</strong>
        <textarea
          aria-label={file.name}
          value={value}
          onChange={(event) => onChange(event.target.value)}
          rows={4}
          style={{ width: "100%" }}
        />
      </label>
    )}
  />
</Demo>

```tsx
<Monaco
  files={[
    { name: "index.ts", value: "console.log('Hello')", language: "typescript" },
  ]}
  renderEditor={({ value, onChange }) => (
    <textarea value={value} onChange={(e) => onChange(e.target.value)} />
  )}
/>
```

## DocsLayout

`DocsLayout` expects a list of normalized `SourcePage` objects, the current URL and its children. Use it in a standalone docs app instead of nesting another full docs shell inside this gallery.

```tsx
import { DocsLayout } from "./components/Layout/DocsLayout";

<DocsLayout
  pages={source.getPages()}
  currentUrl="/guide"
  title="My Docs"
  toc={{ headings: [{ id: "intro", value: "Intro", depth: 2 }] }}
>
  <article>
    <h1>Guide</h1>
    <h2 id="intro">Intro</h2>
  </article>
</DocsLayout>;
```

## DocsRoutes

`HeadlessDocsRoutes` is router-independent and takes a `MoyaForgeSource` generated by the content system; it selects and renders the matching page.

```tsx
import { HeadlessDocsRoutes } from "@moyarich/moyaforge/headless";

export function Documentation({ source, pathname }) {
  return (
    <HeadlessDocsRoutes
      source={source}
      pathname={pathname}
      layout={{ title: "My Documentation" }}
      notFound={<p>Not found</p>}
    />
  );
}
```

## Additional editor variants

The Monaco package also exports integrations such as `MonacoCodeGroup` and source editors. They require editor-specific dependencies and setup; use them when integrating a real code editor rather than the textarea adapter shown above.
