# CodeBlock

Style and copy a syntax-highlighted code block.

## Preview

<Demo>
  <p>The example below is rendered and syntax-highlighted by the shared MDX compiler.</p>
</Demo>

```tsx
export function Greeting() {
  return <p>Hello MoyaForge</p>;
}
```

## Usage

```tsx
import { CodeBlock } from "@moyarich/moyaforge";

<CodeBlock language="tsx"><code>{"const greeting = 'Hello';"}</code></CodeBlock>
```
