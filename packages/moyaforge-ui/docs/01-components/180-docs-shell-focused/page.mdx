# Docs Shell Focused

Use `DocsShellFocused` for articles and guides that need a readable content width
without a sidebar. Supply the article as children; add navigation, actions, and
footer content only when the page needs them.

## Installation

```sh
npx @moyarich/moyaforge-cli@latest add docs-shell-focused
```

Or install with the shadcn CLI:

```sh
npx shadcn@latest add moyarich/moyaforge/docs-shell-focused
```

Both commands copy the component and its CSS into your project.

## Usage

The example uses `@/` as an alias for `src/`. Adjust the import to match your
installation directory.

```tsx
import { DocsShellFocused } from "@/components/ui/DocsShellFocused";

export default function WritingGuide() {
  return (
    <DocsShellFocused
      title="Write for the next reader"
      subtitle="A practical guide to useful documentation · 3 min read"
      backHref="/guides"
      footer={<p>Continue with the next guide when you are ready.</p>}
    >
      <h2>Begin with a real task</h2>
      <p>Give the page a clear purpose and a complete, working example.</p>
    </DocsShellFocused>
  );
}
```

`backHref` creates a normal back link. Your application owns routing; the shell
does not load pages or change the article for you.

## Slots

| Prop | What it renders |
| --- | --- |
| `title`, `subtitle` | Default heading and introduction. |
| `header` | Replaces the default heading. Leave it undefined to use `title` and `subtitle`; pass `null` to omit it. |
| `navigation` | Replaces the `backHref` link. Pass `null` to hide it. |
| `articleActions` | Actions alongside the heading, such as saving an article. |
| `children` | The article content. |
| `footer` | Optional chapter navigation or related content. |

Passing a custom `header` replaces the title and subtitle display, so include
those elements in your custom content if you still want them visible.

## Styling

The component imports its own structural CSS. Set `--mf-focused-width` to change
the centered reading width and `--mf-focused-border` for header and footer dividers.
Style your supplied article and actions with your own classes.

```css
.my-reading-page {
  --mf-focused-width: 44rem;
  --mf-focused-border: light-dark(#e4e4e7, #3f3f46);
}
```

Apply these overrides on a wrapper around `DocsShellFocused`. Public variables
use `--mf-*`; component-private variables use `--_mf-*`.
