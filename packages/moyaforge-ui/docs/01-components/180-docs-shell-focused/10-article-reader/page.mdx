# Article reader

Read two chapters using **Next** and **Previous**. **Save guide** toggles a local
saved state; it does not write to storage.

`title` and `subtitle` use the shell’s default header. `articleActions` supplies
the save button, `footer` supplies chapter controls, and `navigation={null}`
omits the back link. The content and interaction state belong to the example.
