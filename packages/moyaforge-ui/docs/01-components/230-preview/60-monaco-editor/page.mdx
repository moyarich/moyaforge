# Editable source with Monaco

Select **Toggle editor** to switch from the counter to an editable panel with TSX and CSS tabs. Edit the TSX or CSS, then select **Toggle editor** again to see the updated counter. TSX edits restart the component. Select **Reset code** to restore the original TSX and CSS.


Install `preview` and `monaco-editor-react`. Follow the [Monaco Editor React setup](/ui/components/monaco-editor-react#installation) to configure the editor workers, then render `MonacoCodeGroup` inside `PreviewSource asChild`.
