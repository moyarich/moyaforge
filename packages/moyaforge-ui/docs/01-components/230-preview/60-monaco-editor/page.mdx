# Editable source with Monaco

Select **Toggle editor** to switch from the counter to an editable panel with TSX and CSS tabs. Edit the TSX or CSS, then select **Toggle editor** again to see the updated counter. TSX edits restart the component. Select **Reset code** to restore the original TSX and CSS.

Install the `code-preview-editor` registry item; it includes the required Preview and Monaco source files and dependencies. With the MoyaForge CLI, run:

```sh
npx @moyarich/moyaforge-cli@latest add code-preview-editor
```

Follow the [Monaco Editor React setup](/ui/components/monaco-editor-react#installation) to configure the editor workers. `CodePreviewEditor` owns the editable files and reset action; its `renderPreview` callback lets each application choose how to render those files.

<CodePreviewEditor
  title="Monaco source editor"
  usageSource={usageSource}
  usageFileName="CodePreviewEditorUsage.tsx"
  files={[
    {
      name: "CounterExample.tsx",
      language: "typescript",
      value: counterSource,
    },
    { name: "counterExample.css", language: "css", value: counterStyles },
    {
      name: "setup-monaco-worker.ts",
      language: "typescript",
      value: workerSource,
      readOnly: true,
    },
  ]}
  height={320}
  renderPreview={(files) => (
    <MonacoPreviewExample
      source={
        files.find((file) => file.name === "CounterExample.tsx")?.value ?? ""
      }
      styles={
        files.find((file) => file.name === "counterExample.css")?.value ?? ""
      }
    />
  )}
/>

## Styling

The example styles live alongside its TSX source; use the `--mf-preview-*` variables for the outer preview frame.
