# Preview

Compose an interactive preview with replaceable header, title, actions, content, source and footer slots.

## Installation

<CodeGroup label="Install Preview">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add preview
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/preview
```

</CodeTab>
</CodeGroup>

The `preview` registry item includes the Preview slots, CopyButton, and their styles. The installers add the required npm dependencies:
React, `lucide-react`, and Shiki. These preview dependencies belong to the documentation
frame; the component being demonstrated may have its own dependencies.

Use [CodePreview](/ui/components/code-preview) when you want a ready-made preview with named source files. Install it with `add code-preview`.

## Usage

The examples use `@/` as an alias for `src/`. Use a relative import if your app has no alias configured.

```tsx
import {
  Preview,
  PreviewHeader,
  PreviewTitle,
  PreviewActions,
  PreviewCodeToggle,
  PreviewCopyButton,
  PreviewContent,
  PreviewSource,
} from "@/components/ui/Preview";
import ButtonExample from "./ButtonExample";
import source from "./ButtonExample.tsx?raw";

<Preview source={source}>
  <PreviewHeader>
    <PreviewTitle>Button</PreviewTitle>
    <PreviewActions>
      <PreviewCodeToggle />
      <PreviewCopyButton />
    </PreviewActions>
  </PreviewHeader>
  <PreviewContent>
    <ButtonExample />
  </PreviewContent>
  <PreviewSource code={source} language="tsx" />
</Preview>;
```

Use `PreviewContent asChild` and `PreviewSource asChild` to compose one DOM-forwarding child, such as a custom layout or editor. `asChild` does not compile or run edited source.

The `?raw` import is supported by Vite. Preview itself does not depend on Vite or MDX; other consumers can pass source strings. You can omit, reorder, or replace slots. The basic `<Preview source={source}>…</Preview>` shorthand still works.

## Styling

Use `--mf-preview-background`, `--mf-preview-border`, `--mf-preview-radius`,
`--mf-preview-padding`, and `--mf-preview-margin` in application CSS.
