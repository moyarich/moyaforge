## Installation

Install Preview for the frame, Code button, and source panel:

```sh
npx @moyarich/moyaforge-cli@latest add preview
```

Install Code Group for the file tabs inside that panel:

```sh
npx @moyarich/moyaforge-cli@latest add code-group
```
