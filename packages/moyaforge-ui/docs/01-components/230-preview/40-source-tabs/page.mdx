# Source files in tabs

Open **Code** to switch between the counter’s React source and stylesheet. Use this pattern when you want to arrange the source panel yourself and let readers copy individual files.

Install `preview` and `code-group`. Place the `CodeGroup` inside `PreviewSource asChild` so the preview toggle controls the whole tab panel.

```tsx
<PreviewSource asChild>
  <div>
    <CodeGroup label="Counter source files">
      <CodeTab label="CounterExample.tsx">
        <pre>
          <code>{source}</code>
        </pre>
      </CodeTab>
      <CodeTab label="counterExample.css">
        <pre>
          <code>{styles}</code>
        </pre>
      </CodeTab>
    </CodeGroup>
  </div>
</PreviewSource>
```
