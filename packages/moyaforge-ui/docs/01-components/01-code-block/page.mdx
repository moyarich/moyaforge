# Code Block

MoyaForge's source-installable `CodeBlock` renders formatted code and includes a copy action. The playground uses the canonical component from `packages/moyaforge-ui/src/components/CodeBlock/`, not a separately maintained example.

## Live preview

The following fenced blocks are rendered as real MoyaForge Code Blocks by the playground's MDX provider. Try copying the code.

```tsx
export function Greeting({ name }: { name: string }) {
  return <p>Hello, {name}!</p>;
}
```

```bash
npm run registry:build
npm run registry:check
```

## Installation

Install the `code-block` registry item with the MoyaForge CLI. Its component source and CSS are copied into your application rather than bundled into `@moyarich/moyaforge`.

## Usage

```tsx
import { CodeBlock } from "@/components/ui/components/CodeBlock";

export function Example() {
  return (
    <CodeBlock>
      <code className="language-ts">const answer = 42;</code>
    </CodeBlock>
  );
}
```

For ordinary documentation code fences, register `CodeBlock` as the MDX `pre` component, as the MoyaForge playground does. Shiki highlighting is optional and happens during MDX compilation.
