# Demo

Preview canonical UI components inside a simple demo container. This live example uses the canonical MoyaForge UI source and is rendered by the playground's MDX provider.

## Installation

<CodeGroup label="Install Demo">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add demo
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/demo
```

</CodeTab>
</CodeGroup>

Install the `demo` component from the MoyaForge component registry. The selected source and CSS are copied into your application; they are not included in the framework package.

[Browse all UI components](/ui)

## Usage

The examples use `@/` as an alias for `src/`. Use a relative import if your app has no alias configured.

```tsx
import { Demo } from "@/components/ui/Demo/Demo";

<Demo>
  <CopyButton value="Hello">Copy greeting</CopyButton>
</Demo>;
```

## Styling

Set `--demo-background`, `--demo-padding`, and `--demo-border-radius` to turn the demo wrapper into a padded surface.
