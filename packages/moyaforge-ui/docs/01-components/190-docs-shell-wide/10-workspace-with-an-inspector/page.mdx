# Docs Shell Wide · Workspace with an inspector

Select a page in the navigation, then edit its title, summary, or status in the
inspector. The center preview updates immediately. Use **Inspector** in the
toolbar to hide or restore the properties panel. Edits stay local to this demo.

This example supplies all five named slots: `header`, `toolbar`, `navigation`,
`inspector`, and `footer`. `PageInspector` is a separate controlled component;
the workspace owns page state and receives property updates through `onChange`.
Pass `null` to `inspector` to remove that panel.
