# Tabs

`Tabs`, `TabsList`, `TabsTrigger`, and `TabsContent` are reusable, editor-independent components. **The tab strip and its content panel share CSS tokens**, rather than requiring a React theme or variant prop.

## Usage

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@moyarich/moyaforge-ui/components/Tabs";

<Tabs defaultValue="content" className="my-tabs">
  <TabsList aria-label="Panels">
    <TabsTrigger value="content">Content</TabsTrigger>
    <TabsTrigger value="source">Source</TabsTrigger>
  </TabsList>
  <TabsContent value="content">Editor content</TabsContent>
  <TabsContent value="source">Source content</TabsContent>
</Tabs>
```

## Theme tokens

Public CSS tokens start with `--mf-`. Supported customization points include `--mf-tabs-surface`, `--mf-tabs-strip`, `--mf-tabs-border`, `--mf-tabs-accent`, `--mf-tabs-active-background`, `--mf-tabs-corner-size`, `--mf-tabs-radius`, `--mf-tabs-indicator-size`, `--mf-tabs-indicator-inset`, `--mf-tabs-content-padding`, and `--mf-tabs-panel-border-width`.

Resolved component-private variables start with `--_mf-`. You can override public tokens on any parent element or through a className.

For controlled selection, use `value` and `onValueChange`. Tabs support arrow keys and Home/End, optional close callbacks, and `forceMount` for panel persistence.
