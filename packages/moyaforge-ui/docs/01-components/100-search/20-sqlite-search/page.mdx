# Search documentation with SQLite

Type **copy button** or **preview** to try the same search field used in the site header. Results appear below the field inside this demo. The SQLite client returns document keys, which the example turns into links using the route metadata.

Press **Alt+Shift+S** to focus the example. The `hotkey` prop sets the shortcut and `kbd` controls the optional label.
