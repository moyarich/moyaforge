# Search

Use Search to collect a query. Connect it to your own results or try the SQLite example below.

## Installation

<CodeGroup label="Install Search">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add search
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/search
```

</CodeTab>
</CodeGroup>

Install the `search` registry item through the MoyaForge CLI to copy editable component source and styles.

## Usage

::: code-preview Search field

<LiveSearch
  inputProps={{
    placeholder: "Find components",
    "aria-label": "Find components",
  }}
/>

:::

The examples use `@/` as an alias for `src/`. Use a relative import if your app has no alias configured.

```tsx
import { Search } from "@/components/ui/Search/Search";

<Search
  inputProps={{
    placeholder: "Find components",
    "aria-label": "Find components",
  }}
/>;
```

## Styling

Set `--mf-search-background`, `--mf-search-border-color`, and `--mf-search-border-radius` to match the input to your form controls.

The field includes a Lucide search icon, a focus ring, and disabled styling. Pass
`icon={null}` to hide the icon, or supply your own through `icon`. Add a `kbd`
child for a visual shortcut hint; keyboard handling remains the host’s responsibility.

Public `--mf-search-*` defaults are defined in `:root`. Override them on a wrapper
or the control. Variables starting with `--_mf-*` are private.

```css
.my-search {
  --mf-search-border-radius: 0.75rem;
  --mf-search-focus-color: var(--mf-accent);
}
```
