# Inline React previews

Add `{react}` to write imports and JSX inside a preview. Each block imports its
own component, so multiple examples can use the same component name. Each preview keeps its imports separate from the page and from other previews.

::::preview-code[Counter with isolated imports]{react}

::preview-code-sources{files="./scope-usage.mdx"}

import Counter from "../../CounterExample.tsx";

<Counter />

::::

## Inline React previews with Named fences

Named fences appear in the Code view and can go before or after the JSX.

::::preview-code[React with source tabs]{react}

::preview-code-sources{files="./usage.mdx"}

```ts filename="config.ts"
export const message = "Hello from React.";
```

import Greeting from "../30-inline-multiple-files/GreetingCard.tsx";

<Greeting />

```css filename="styles.css"
.greeting {
  font-weight: 600;
}
```
