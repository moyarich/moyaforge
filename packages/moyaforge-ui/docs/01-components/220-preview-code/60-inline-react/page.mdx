# Inline React previews

Select a named TSX fence with `preview` to render its default-exported component. Each module keeps its imports separate from the page and other previews.

::::preview-code[Counter with isolated imports]{preview="Example.tsx"}

```tsx filename="Example.tsx"
import Counter from "../../CounterExample.tsx";

export default function Example() {
  return (
    <Counter />
  );
}
```

## Inline React previews with Named fences

Every named fence appears in the Code view. Select the entry module with `preview`.

::::preview-code[React with source tabs]{preview="Example.tsx"}

```tsx filename="Example.tsx"
import Greeting from "../30-inline-multiple-files/GreetingCard.tsx";

export default function Example() {
  return (
    <Greeting />
  );
}
```

```ts filename="config.ts"
export const message = "Hello from React.";
```

```css filename="styles.css"
.greeting {
  font-weight: 600;
}
```

## TypeScript previews

React previews support TypeScript annotations, type declarations, generics, and assertions. The preview body is compiled as TSX, so these features work without changing the surrounding MDX syntax. The default-exported component renders the example, and the Code view retains the original TypeScript.

::::preview-code[TypeScript example]{preview="Example.tsx"}

```tsx filename="Example.tsx"
type Item = { name: string };
const items: Item[] = [{ name: "Example" }];
const identity = <T,>(value: T): T => value;

export default function Example() {
  return (
    <p>{identity(items[0].name) as string}</p>
  );
}
```
