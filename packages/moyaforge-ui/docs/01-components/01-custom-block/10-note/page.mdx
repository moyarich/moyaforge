# Note

Use a note for information readers may want to know while following the main instructions, such as where their drafts are saved.

## Minimal blue note

A simple left-accented note with a subtle blue background.

::::code-preview[Minimal blue note]{react replacements="portable"}

import { CustomBlock } from "../../../../src/components/CustomBlock/index.js";

<div className="note-preview-blue">
  <style>{`
    .note-preview-blue .custom-block.note {
      --mf-custom-block-bg: color-mix(in srgb, #2563eb 8%, transparent);
      --mf-custom-block-border: #2563eb;
      --mf-custom-block-border-width: 4px;
      --mf-custom-block-radius: 8px;
    }
  `}</style>

  <CustomBlock type="note" title="Where drafts are saved">
    Drafts are saved in your browser.
  </CustomBlock>
</div>

::::

::::code-preview[Markdown teal note]{replacements="portable"}

<style data-note-preview="teal">{`
  style[data-note-preview="teal"] + .custom-block.note {
    --mf-custom-block-bg: color-mix(in srgb, #149e92 8%, transparent);
    --mf-custom-block-border-width: 0px;
    --mf-custom-block-radius: 8px;

    padding: 1rem 1.25rem;
