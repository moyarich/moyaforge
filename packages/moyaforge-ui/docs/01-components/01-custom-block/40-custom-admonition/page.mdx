# Custom admonition

Custom callouts use the same Markdown directive syntax as notes and warnings. Choose any callout type, then customize its CSS. These English examples use soft colors, clear headings, and simple status icons inspired by [Sharia Design's Alerts + Notifications](https://dribbble.com/shots/14440808-UI-Compontents-Alerts-Notifications).

Each example is written as Markdown with a raw inline CSS block. The Code view shows the original Markdown, CSS, and JavaScript rather than generated React. Use a unique type name to keep its styling separate from other callouts.

## Success — mint notification

<style>
.custom-block.ui-success {

  --mf-custom-block-border-width: 0;

  box-shadow: 0 4px 16px #0b81541a;
}

  content: "✓";
  position: absolute;

  display: grid;
  place-items: center;
  width: 1.55rem;
  height: 1.55rem;
  border-radius: 50%;
  background: #19a56b;
  color: white;
  font-weight: 800;
}

  color: #12643e;
  font-size: 0.95rem;
}

## Expandable notification — script source only

The raw `<script>` is visible in the Source tab, but it does not execute in the preview. The native `<details>` element below supplies a working interaction without JavaScript.

::::code-preview[Dismissible notification]

<style>
.custom-block.ui-dismissible {
  --mf-custom-block-bg: #eef0ff;
  --mf-custom-block-border-width: 0;
  --mf-custom-block-padding: 1rem 3rem 1rem 1.25rem;
  --mf-custom-block-radius: 14px;
  position: relative;
  border: 1px solid #c9c7ff;
  color: #51468c;
}
.custom-block.ui-dismissible .custom-block-title {
  color: #5140a3;
}
.custom-block.ui-dismissible .ui-notification-details summary {
  color: #5140a3;
  font-weight: 600;
  cursor: pointer;
}
.custom-block.ui-dismissible .ui-notification-details[open] summary {
  margin-bottom: 0.5rem;
}
</style>

::: ui-dismissible Your download is ready

<details className="ui-notification-details"><summary>Show download information</summary><p>Your file has been prepared and is ready to download.</p></details>

:::
