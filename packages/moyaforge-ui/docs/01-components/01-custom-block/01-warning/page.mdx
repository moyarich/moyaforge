# Warning

Place a warning before a step where readers need to take action, such as saving a backup before changing settings.

## React Component (MDX)

::::code-preview[Warning callout]{react replacements="portable"}
::code-preview-sources{files="./example.css"}
import { CustomBlock } from "../../../../src/components/CustomBlock/index.js";
import "./example.css";

<CustomBlock type="warning" title="Before you continue">
  Save a backup before changing your settings.
</CustomBlock>
::::
