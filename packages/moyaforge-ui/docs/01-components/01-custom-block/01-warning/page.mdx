## Markdown Source

Write the warning directly in Markdown. The title follows `warning`, and the body supports Markdown formatting.

::::code-preview[Inline Markdown warning]{preview="example.md"}

```css filename="example.css"
.custom-block.warning.warning-example,
.warning-example .custom-block.warning {
  --mf-custom-block-bg: color-mix(in srgb, #b45309 12%, transparent);
  --mf-custom-block-border: #b45309;
}
```

```md filename="example.md"
::: warning Before you continue

Save a **backup** before changing your settings.

- Export your current configuration.
- Keep the backup somewhere safe.

Read the [component documentation](../) before continuing.

:::
```
