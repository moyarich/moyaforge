# Warning

Place a warning before the step where readers need to take action, such as saving a backup before changing settings.

## React Component

::::code-preview[Warning callout]{react}

import "./Example.css";
import { CustomBlock } from "../../../../src/components/CustomBlock/index.js";

<div className="warning-example">
  <CustomBlock type="warning" title="Before you continue">
    Save a backup before changing your settings.
  </CustomBlock>
</div>

::code-preview-sources{files="./Example.css" replacements="portable"}

::::
