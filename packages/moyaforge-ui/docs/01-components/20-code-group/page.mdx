# Code Group

Present related code examples in tabs, such as install commands for different package managers.

## Installation

<CodeGroup label="Install Code Group">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add code-group
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/code-group
```

</CodeTab>
</CodeGroup>

The installer copies the component source and CSS into your project.

## Usage

The examples use `@/` as an alias for `src/`. Use a relative import if your app has no alias configured.

```tsx
import { CodeGroup, CodeTab } from "@/components/ui/CodeGroup/CodeGroup";

<CodeGroup label="Package managers">
  <CodeTab label="npm">
    <pre>
      <code>npm install react</code>
    </pre>
  </CodeTab>
  <CodeTab label="pnpm">
    <pre>
      <code>pnpm add react</code>
    </pre>
  </CodeTab>
</CodeGroup>;
```

## Styling

Set public CSS variables on the group or a containing element:

```css
.install-commands {
  --mf-code-group-active-color: #0f766e;
  --mf-code-group-tabs-gap: 20px;
  --mf-code-group-border-radius: 10px;
}
```

| Variable                        | Purpose                          |
| ------------------------------- | -------------------------------- |
| `--mf-code-group-active-color`  | Selected tab text and underline. |
| `--mf-code-group-tabs-gap`      | Space between tab labels.        |
| `--mf-code-group-background`    | Code surface background.         |
| `--mf-code-group-border`        | Group and toolbar borders.       |
| `--mf-code-group-border-radius` | Outer corner radius.             |
| `--mf-code-group-padding`       | Code panel padding.              |

Use Left/Right arrow keys, Home, and End to switch tabs from the keyboard. The copy button copies the active tab's code.
