## Use these tabs in Markdown

Use a `code-group` directive with one `tab` per package manager. Copy the **example.md** source tab into your Markdown file. The `preview-code` wrapper is used only by this documentation.

### Install the MDX tooling

If your app does not already process Markdown, install the compiler and React provider:

```sh
npm install @mdx-js/react
npm install -D @mdx-js/rollup @vitejs/plugin-react vite @moyarich/moyaforge-mdx
```

The following setup assumes an existing React application with TypeScript support.

### Configure Vite

Map the `code-group` directive and its nested `tab` directives. If your app already calls `createMdxOptions`, add this entry to its existing `componentMappings` map.

```ts filename="vite.config.ts"
import mdx from "@mdx-js/rollup";
import { createMdxOptions } from "@moyarich/moyaforge-mdx";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    {
      ...mdx(
        createMdxOptions({
          componentMappings: {
            "code-group": {
              component: "CodeGroup",
              childType: "tab",
              childComponent: "CodeTab",
            },
          },
        }),
      ),
      enforce: "pre",
    },
    react({ include: /\.(?:js|jsx|md|mdx|ts|tsx)$/ }),
  ],
});
```

### Register the components

Import both installed components and register them under the names used in the Vite config. Copy the example from **Code** into `src/Guide.md`.

```tsx filename="src/App.tsx"
import { MDXProvider } from "@mdx-js/react";
import { CodeGroup, CodeTab } from "./components/ui/CodeGroup/CodeGroup.js";
import Guide from "./Guide.md";

export function App() {
  return (
    <MDXProvider components={{ CodeGroup, CodeTab }}>
      <Guide />
    </MDXProvider>
  );
}
```
