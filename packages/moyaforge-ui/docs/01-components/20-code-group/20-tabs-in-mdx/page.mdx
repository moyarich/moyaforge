# Tabs in MDX

Import `CodeGroup` and `CodeTab` in your `.mdx` file. Wrap each fenced code block in a `CodeTab` and give the group a label. Open **Code** to copy the complete example. The displayed import uses `@/` as an alias for `src/`; replace it with your component path if your application has no alias. The components import their own styles.
