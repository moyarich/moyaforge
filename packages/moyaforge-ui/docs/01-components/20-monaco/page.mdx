# Monaco

This live demo uses Monaco's pluggable editor interface with a lightweight text area. Full editor engines are optional and only needed when a consumer explicitly selects one.

## Live preview

import { Monaco } from "../../../src/components/Monaco/Monaco.tsx";

<Monaco
  files={[
    {
      name: "example.ts",
      language: "typescript",
      value: "export const greeting = 'Hello';",
    },
    {
      name: "example.css",
      language: "css",
      value: ".preview { display: grid; }",
    },
  ]}
  renderEditor={({ file, value, onChange }) => (
    <textarea
      aria-label={file.name}
      value={value}
      onChange={(event) => onChange(event.target.value)}
      rows={5}
      style={{ width: "100%" }}
    />
  )}
/>
