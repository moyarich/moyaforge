# Sidebar V1

This example uses the real source-owned MoyaForge UI component. It does not create a second component implementation or application router.

## Usage

The examples use `@/` as an alias for `src/`. Use a relative import if your app has no alias configured.

```tsx
import { SidebarV1 } from "@/components/ui/SidebarV1/SidebarV1";

<SidebarV1
  label="Documentation"
  pages={[
    { url: "/ui", title: "Overview" },
    { url: "/ui/components/sidebar-v1", title: "Sidebar V1" },
  ]}
  currentUrl="/ui/components/sidebar-v1"
/>;
```

Use `pages` for a flat list and `groups` for section headings and nested navigation.
Each group has a `source`, `label`, and `nodes`; set `collapsible` with a group
`page` to show a separate disclosure control. See the grouped demo below for
complete data and local selection handling.

When `currentUrl` is provided, grouped links use it to mark the active page.
Without it, grouped navigation follows the React Router location.

## Styling

When embedding the sidebar in an article, use an instance class to give it a local width and keep it in normal flow. The example’s CSS overrides the documentation shell’s sticky desktop and hidden mobile sidebar rules.

## Scrolling and long labels

Navigation scrolls independently while the header and footer remain visible. Subtle fades appear at the top or bottom only when more content is available in that direction. Labels stay on one line and truncate with an ellipsis by default.

Enable wrapping when you prefer to show the full label:

```tsx
<SidebarV1 groups={groups} wrapNavigation />
```

Keep the default with `<SidebarV1 groups={groups} />`. Custom navigation supplied as children uses the same scrolling area.

For a draggable boundary between navigation and content, compose the sidebar inside a [ResizablePanel](/ui/components/resizable-panels). Resize behavior belongs to the panel group, so the same components can also divide an editor and preview.

## Scrollbar and resize colors

Public variables customize the colors in light and dark themes:

```css
.my-docs {
  --mf-sidebar-scrollbar: light-dark(#c4c4c4, #555555);
  --mf-sidebar-scrollbar-hover: light-dark(#a3a3a3, #737373);
  --mf-sidebar-resize-border: light-dark(#e9e9ed, #303039);
  --mf-sidebar-resize-hover: light-dark(#a3a3a3, #737373);
}
```

Apply the class to the documentation site container. Variables beginning with `--_mf-` are component-private implementation values. For standalone resize groups, use `--mf-resizable-border` and `--mf-resizable-accent`.
