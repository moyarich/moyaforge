# Documentation Site · Standalone documentation site

Switch pages through the sidebar, search, breadcrumbs, or previous/next links.
The example keeps `currentPath` in React state and passes `onNavigate` to the
shell, so navigation stays inside the preview without a router.

The default sidebar and breadcrumbs read `path`, `title`, and `parentPath` from
the supplied pages. `onSearch` searches those same pages. `outline={null}` omits
the optional outline. The example CSS contains the full-page layout inside this
preview; the component supplies the navigation and control styling.
