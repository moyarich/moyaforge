# Fade and slide

Combine an opacity fade with a small upward movement. Use **Refresh** to replay the animation.

::::code-preview[Fade and slide]{refresh preview="WelcomeNotice.tsx" replacements="portable"}

```tsx filename="WelcomeNotice.tsx"
import { Animation } from "../../../../src/components/Animation/index.js";
import "./WelcomeNotice.css";

export default function WelcomeNotice() {
  return (
    <Animation effect="fade-slide" duration={0.9} wait={0.4} distance={24} className="animation-fade-slide-example">
      <h2>Welcome back</h2>
      <p>Pick up where you left off in your workspace.</p>
    </Animation>
  );
}
```

```css filename="WelcomeNotice.css"
.animation-fade-slide-example {
  width: min(100%, 26rem);
  padding: 1.5rem;
  border: 1px solid color-mix(in srgb, currentColor 14%, transparent);
  border-radius: 0.75rem;
  background: color-mix(in srgb, currentColor 3%, transparent);
  text-align: start;
}

.animation-fade-slide-example h2 {
  margin: 0 0 0.5rem;
  padding: 0;
  border: 0;
  font-size: 1.25rem;
  line-height: 1.4;
}

.animation-fade-slide-example p {
  margin: 0;
  font-size: 0.9375rem;
  line-height: 1.7;
}
```

::::

`duration` and `wait` are measured in seconds. Reduced-motion preferences show
the finished content immediately.
