# Animation

Use `Animation` for a single effect and `AnimationGroup` to coordinate several effects.

Change the group's React `key` to replay it from the beginning.

## Installation

```sh
npx @moyarich/moyaforge-cli@latest add animation
```

Import the copied components from `@/components/ui/Animation/index.js`, or use a relative path when your app has no `@/` alias. Their styles are imported by the components.

## Usage

This example uses the default `fade-slide` effect. Select **Refresh** to replay it.

::::code-preview[Welcome message]{refresh preview="WelcomeMessage.tsx" replacements="portable"}

```tsx filename="WelcomeMessage.tsx"
import { Animation } from "../../../src/components/Animation/index.js";

export default function WelcomeMessage() {
  return (
    <Animation duration={0.9} wait={0.4} distance={16}>
      <p>Welcome to your workspace. Make something worth sharing.</p>
    </Animation>
  );
}
```

::::

## Options

Both components accept a `className` string, array, or conditional object.

```tsx
<Animation effect="fade" className={["message", { featured: isFeatured }]}>
  <p>Welcome to the guide.</p>
</Animation>
```

| Option             | Description                                                                                                       |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `effect`           | `fade`, `slide`, `fade-slide` (default), `reveal`, or `typewriter`. Use the typewriter effect for static text.    |
| `sequence` (group) | Wait for the previous entry to finish. Defaults to `false`.                                                       |
| `duration`         | Effect duration in seconds. Defaults to `0.3`.                                                                    |
| `wait`             | Initial delay in seconds. Defaults to `0`.                                                                        |
| `stagger` (group)  | Delay in seconds between sequential entries. For independent entries, adds this delay per index. Defaults to `0`. |
| `distance`         | Vertical offset in pixels for slide effects. Defaults to `12`.                                                    |

`expand` on `AnimationGroup` defaults to `false`. Enable it when sequential content should reveal its layout progressively, as in the terminal example.

Entries show their content immediately when the user prefers reduced motion.
