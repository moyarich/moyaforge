# Fade in

Use `effect="fade"` to animate opacity without moving the content.

## Simple fade

::::code-preview[Simple fade]{refresh preview="SimpleFade.tsx" replacements="portable"}

```tsx filename="SimpleFade.tsx"
import { Animation } from "../../../../src/components/Animation/index.js";

export default function SimpleFade() {
  return (
    <Animation effect="fade" duration={1.6} wait={1}>
      <p>Hello, welcome to your workspace.</p>
    </Animation>
  );
}
```

::::

## Fade in a confirmation card

Reveal a confirmation card without moving it.
The dotted background stays visible while the card fades from transparent to opaque over `1.6` seconds.

Set `duration` and `wait` in seconds to tune the reveal.

::::code-preview[Fade in a confirmation card]{refresh preview="FadeInCard.tsx" replacements="portable"}

```tsx filename="FadeInCard.tsx"
import { Check, FileText } from "lucide-react";
import { Animation } from "../../../../src/components/Animation/index.js";
import "./FadeInCard.css";

export default function FadeInCard() {
  return (
    <div className="fade-in-stage">
      <Animation
        effect="fade"
        duration={1.6}
        wait={1}
        className="fade-in-reveal"
      >
        <section className="fade-in-card" aria-label="Workspace confirmation">
          <span className="fade-in-card-icon" aria-hidden="true">
            <Check size={22} strokeWidth={2} />
          </span>
          <p className="fade-in-card-eyebrow">All set</p>
          <h2>Your workspace is ready.</h2>
          <p className="fade-in-card-description">
            A place for your ideas, guides, and everything you build next.
          </p>
          <div className="fade-in-card-footer">
            <FileText size={16} aria-hidden="true" />
            Start with your first page
          </div>
        </section>
      </Animation>
    </div>
  );
}
```
