# Components

Install editable components with the MoyaForge CLI or shadcn. Every example page uses **CodePreview** to pair the interactive result with its actual authored source files. Select **Preview** to try the component and **Code** to inspect or copy its TSX, MDX, CSS, and setup files.\n\nComponent examples load their sibling `Example.tsx` as the preview and source, rather than maintaining a separate code snippet. [Learn how to author a CodePreview](/ui/components/code-preview).
