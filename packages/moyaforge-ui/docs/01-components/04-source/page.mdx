# Source

Render code as a source snippet without an interactive editor. This live example uses the canonical MoyaForge UI source and is rendered by the playground's MDX provider.

## Installation

Install the `source` component from the MoyaForge component registry. The selected source and CSS are copied into your application; they are not included in the framework package.
