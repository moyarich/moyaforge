# Preview

`Preview` renders an interactive React example and can show or copy its source. Write examples in standalone `.tsx` files, just like Material UI's component documentation. The example imports its own `.css` file; MDX only imports the example.

## File structure

```text
22-preview/
├── page.mdx
├── PreviewExample.tsx
└── PreviewExample.css
```

## Usage

```mdx
import PreviewExample from "./PreviewExample.tsx";

<PreviewExample />
```

```tsx
// PreviewExample.tsx
import "./PreviewExample.css";
import { Preview } from "../../../src/components/Preview/Preview.js";

// Write a normal React component; the MDX page only imports it.
export default function PreviewExample() {
  return (
    <Preview title="Button" source={'<button type="button">Click me</button>'}>
      <button type="button">Click me</button>
    </Preview>
  );
}
```

Preview does not serialize React children. The example supplies source text directly; future MDX tooling can automatically load raw `.tsx` source separately from the live component.

## Theme variables

Set `--mf-preview-background`, `--mf-preview-border`, `--mf-preview-radius` and `--mf-preview-padding` from application CSS.
