# Code Group

Switch between npm and pnpm command examples. This live example uses the canonical MoyaForge UI source and is rendered by the playground's MDX provider.

## Live preview

<CodeGroup label="Installation commands">
  <CodeTab label="npm">
    <pre>npm install @moyarich/moyaforge</pre>
  </CodeTab>
  <CodeTab label="pnpm">
    <pre>pnpm add @moyarich/moyaforge</pre>
  </CodeTab>
</CodeGroup>

## Usage

```tsx
<CodeGroup label="Package managers">
  <CodeTab label="npm">
    <pre>npm install my-package</pre>
  </CodeTab>
  <CodeTab label="pnpm">
    <pre>pnpm add my-package</pre>
  </CodeTab>
</CodeGroup>
```

## Installation

Install the `code-group` component from the MoyaForge component registry. The selected source and CSS are copied into your application; they are not included in the framework package.

[Browse all UI components](/ui)

## Markdown directive syntax

This playground configures the generic directive mapper so `code-group` becomes a React `CodeGroup` and its nested `tab` directives become `CodeTab` components. The shared parser does not hardcode either name.

:::: code-group Package managers

::: tab npm

```bash
npm install example-package
```

:::

::: tab pnpm

```bash
pnpm add example-package
```

:::

::::

The equivalent Markdown source:

```md
:::: code-group Package managers

::: tab npm
\`\`\`bash
npm install example-package
\`\`\`
:::

::: tab pnpm
\`\`\`bash
pnpm add example-package
\`\`\`
:::

::::
```

Consumers can opt into this behavior with `createMdxOptions({ directiveComponents: { "code-group": { component: "CodeGroup", childType: "tab", childComponent: "CodeTab" } } })`. Unknown directive names remain generic custom blocks.
