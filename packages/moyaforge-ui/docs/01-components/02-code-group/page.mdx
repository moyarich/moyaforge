# Code Group

Switch between npm and pnpm command examples. This live example uses the canonical MoyaForge UI source and is rendered by the playground's MDX provider.

## Live preview

<CodeGroup label="Installation commands">
  <CodeTab label="npm">
    <pre>npm install @moyarich/moyaforge</pre>
  </CodeTab>
  <CodeTab label="pnpm">
    <pre>pnpm add @moyarich/moyaforge</pre>
  </CodeTab>
</CodeGroup>

## Usage

```tsx
<CodeGroup label="Package managers">
  <CodeTab label="npm">
    <pre>npm install my-package</pre>
  </CodeTab>
  <CodeTab label="pnpm">
    <pre>pnpm add my-package</pre>
  </CodeTab>
</CodeGroup>
```

## Installation

Install the `code-group` component from the MoyaForge component registry. The selected source and CSS are copied into your application; they are not included in the framework package.
