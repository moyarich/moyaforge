# Table of Contents · Outline from page headings

Click an outline link to select it immediately and keep it selected until smooth
scrolling finishes. Scrolling manually instead selects the heading in view; wheel,
touch, scrollbar, and keyboard input release the clicked selection. Second- and third-level headings show the outline hierarchy.

The example passes explicit `items` and uses `renderLink` for local scrolling and
`aria-current`. In an MDX site, build these items from compiler-provided headings
so their IDs match the rendered headings.
