# Table of Contents

This live example uses the canonical component source in `packages/moyaforge-ui/src/components/`.

## Installation

<CodeGroup label="Install Table of Contents">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add table-of-contents
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/table-of-contents
```

</CodeTab>
</CodeGroup>

Install the `table-of-contents` registry item through the MoyaForge CLI to copy editable component source and styles.

[UI Components](/ui)

## Usage

The examples use `@/` as an alias for `src/`. Use a relative import if your app has no alias configured.

```tsx
import { TableOfContents } from "@/components/ui/TableOfContents/TableOfContents";

<TableOfContents selector="h2[id], h3[id]" />;
```

## Styling

Set `--mf-toc-indent` for nested headings, `--mf-toc-gap` for vertical spacing, and `--mf-toc-color` for link text.

Link spacing, indentation, hover, focus, and active-heading styles are included in
the component. Public defaults live in `:root`; override `--mf-toc-accent`,
`--mf-toc-active-background`, `--mf-toc-font-size`, or `--mf-toc-link-padding`
on a wrapper or the component. Private variables use the `--_mf-*` prefix.

For custom links returned by `renderLink`, set `aria-current="location"` on the
active heading to use the built-in selected styling. The example’s CSS only
controls its two-column layout and scrollable article.
