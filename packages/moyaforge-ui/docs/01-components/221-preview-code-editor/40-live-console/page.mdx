# Live console

Click the counter, then select **Show Console** to inspect the captured messages. Hide the console, click the counter again and reopen it: messages are retained. Switch to Code to edit the event handler and add your own console calls.

The example uses the standalone Console package and a scoped console proxy. The host compiles trusted local source with Sucrase; it does not replace the global browser console or sandbox code.
