## Usage

```tsx

  title="Example site"
  pages={[{ path: "/ui", label: "Overview" }]}
  currentPath="/ui"
  sidebar={null}
  outline={null}

  <p>Standalone documentation chrome with host-owned routing.</p>
</DocumentationSite>
```
