# Monaco Editor TypeFox

A multi-file code editor with read-only mode and copy support.

## Installation

<CodeGroup label="Install Monaco Editor TypeFox">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add monaco-editor-type-fox
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/monaco-editor-type-fox
```

</CodeTab>
</CodeGroup>

In an existing React app, ensure these runtime dependencies are installed:

```sh
npm install @typefox/monaco-editor-react@~8.0.2 monaco-languageclient@~11.0.2 @codingame/monaco-vscode-editor-api@^37.6.1 lucide-react
```

For Vite, copy `setup.ts` from the preview’s Code tab and import it before the editor. It configures local Monaco workers. Other bundlers need their own worker setup.

## Usage

The examples use `@/` as an alias for `src/`. Use a relative import if your app has no alias configured.

```tsx
import "./setup";
import { MonacoEditorTypeFox } from "@/components/ui/MonacoEditorTypeFox/MonacoEditorTypeFox";

<MonacoEditorTypeFox
  files={[
    { name: "index.ts", value: "const answer = 42;" },
    { name: "styles.css", value: "body { margin: 0; }" },
  ]}
  height={320}
/>;
```

Use `onSave` to handle Save or Ctrl/Cmd+S and persist changes. Use `onFileChange` to track edits.

<details>
<summary>Advanced options</summary>

- `activeFile` and `onActiveFileChange` control the selected file.
- `theme` overrides the inherited light/dark appearance.
- `options`, `vscodeApiConfig`, `onReady`, and `onError` customize TypeFox.
- `showCopyButton` and `showFileTabs` control toolbar visibility.
- `className` and `--monaco-*` CSS variables customize styling.

The installed `components/MonacoEditorTypeFox/README.md` includes additional dependency and setup guidance.

</details>

## Styling

Customize the editor using `className` and the public `--monaco-*` CSS variables described in Advanced options.
