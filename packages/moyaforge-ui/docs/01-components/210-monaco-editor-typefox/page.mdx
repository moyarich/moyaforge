# Monaco Editor TypeFox

The Monaco editing runtime is provided by `moyaforge-monaco`; tabs, actions and editor layout are provided by `moyaforge-ui`.

## Installation

<CodeGroup label="Install TypeFox editor panel">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add type-fox-editor-panel
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/type-fox-editor-panel
```

</CodeTab>
</CodeGroup>

In an existing React app, ensure these runtime dependencies are installed:

```sh
npm install @moyarich/moyaforge-ui @moyarich/moyaforge-monaco @typefox/monaco-editor-react@~8.0.2 monaco-languageclient@~11.0.2 @codingame/monaco-vscode-editor-api@^37.6.1 lucide-react
npm install @codingame/monaco-vscode-standalone-languages@^37.6.1 @codingame/monaco-vscode-standalone-typescript-language-features@^37.6.1 @codingame/monaco-vscode-standalone-css-language-features@^37.6.1 @codingame/monaco-vscode-standalone-json-language-features@^37.6.1 @codingame/monaco-vscode-standalone-html-language-features@^37.6.1
```

For Vite, register `monacoReactTypesPlugin(import.meta.dirname)` from `@moyarich/moyaforge-monaco/vite/monacoReactTypesPlugin` in `vite.config.ts` and call `configureTypeFoxWorkers()` from `@moyarich/moyaforge-monaco/workers/configureTypeFoxWorkers` once at application startup. If using React Monaco too, call `initializeSharedMonaco()` from `/runtime/initializeSharedMonaco` instead. Other bundlers need their own worker setup.

For editor worker architecture and shared initialization details, see [Monaco runtime](../../../../../docs/04-development/30-monaco-runtime/page.mdx).

The editor setup belongs in your application's `main.tsx`, **not** inside the component. For standalone TypeFox applications:

```ts
import { configureTypeFoxWorkers } from "@moyarich/moyaforge-monaco/workers/configureTypeFoxWorkers";

configureTypeFoxWorkers();
```

## Usage

::: preview-code TypeFox panel

<LiveMonacoEditorTypeFox
  files={[{ name: "index.ts", value: "const answer = 42;" }]}
  height={320}
/>

:::

The interactive panel comes from `moyaforge-ui`; the headless `MonacoEditorTypeFox` runtime remains available from `moyaforge-monaco` for custom shells. To install only the runtime source, use `add monaco-editor-typefox`.

```tsx
import { TypeFoxEditorPanel } from "@moyarich/moyaforge-ui/components/TypeFoxEditorPanel";

<TypeFoxEditorPanel
  files={[
    { name: "index.ts", value: "const answer = 42;" },
    { name: "styles.css", value: "body { margin: 0; }" },
  ]}
  height={320}
/>;
```

The UI panel owns tabs, Save, and Copy actions. Keep files in React state via `onFileChange`; `onSave` receives the active file's latest value.

To connect a language server, pass `languageClientConfig` with the same configuration accepted by TypeFox's `MonacoEditorReactComp` (typed as `LanguageClientConfig` from `monaco-languageclient/lcwrapper`):

```tsx
<TypeFoxEditorPanel
  files={files}
  languageClientConfig={languageClientConfig}
/>
```

The host must provide a running language server and its transport; MoyaForge does not start one. Initialize shared VS Code services once at application startup when mounting both Monaco integrations.

## Styling

Customize the panel using `className`, `--mf-tabs-*`, and `--mf-editor-*` CSS variables. The underlying Monaco runtime is UI-free.

## Customize styling with your CSS

Create `editor.css` **in your application**, import it into your React component, and pass a scoped class to `TypeFoxEditorPanel`:

```tsx
import { TypeFoxEditorPanel } from "@moyarich/moyaforge-ui/components/TypeFoxEditorPanel";
import "./editor.css";

<TypeFoxEditorPanel
  className="typefox-editor"
  files={files}
  height={320}
/>;
```

```css
/* editor.css — user-owned, not a MoyaForge internal stylesheet */
.typefox-editor {
  --mf-editor-border: #cbd5e1;
  --mf-editor-toolbar-background: #f1f5f9;
  --mf-editor-surface: #fff;
  --mf-tabs-accent: #2563eb;
  --mf-tabs-indicator-size: 3px;
  --mf-tabs-active-color: #1d4ed8;
}
```

You can also set `--mf-tabs-corner-size`, `--mf-tabs-active-background`, and `--mf-tabs-radius` to customize the tab shape and panel surface. The CSS variables style the **editor UI**, not the underlying Monaco syntax theme. See [Editor Panel](/ui/components/editor-panel) for an editable, stateful example and curved-tab CSS preset.
