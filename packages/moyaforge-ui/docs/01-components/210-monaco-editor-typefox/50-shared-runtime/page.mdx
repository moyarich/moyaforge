# React Monaco and TypeFox together

Both editors can appear in one React tree when they use the **same VS Code-compatible Monaco runtime**. Initialize the shared services before mounting either editor, rather than importing both standalone worker setup entry points.

## Vite setup

Register `monacoReactTypesPlugin(projectRoot)` from `@moyarich/moyaforge-monaco/vite`. Install the optional peer dependencies for both editors, including `@codingame/monaco-vscode-editor-api` and the matching `@codingame/monaco-vscode-standalone-*` packages.

## Initialize once before rendering

```tsx filename="main.tsx"
import { createRoot } from "react-dom/client";
import { initializeSharedMonaco } from "@moyarich/moyaforge-monaco/shared";
import { App } from "./App.js";

await initializeSharedMonaco();

createRoot(document.getElementById("root")!).render(<App />);
```

`initializeSharedMonaco()` safely reuses one initialization promise across callers and React StrictMode mounts. It configures TypeFox's worker factory, points `@monaco-editor/react` at the same editor API, and initializes VS Code services before either editor starts.

Do **not** also import `/react/auto` or `/typefox/auto`. A shared runtime uses compatible worker scripts and protocol; it does not require sharing one running Web Worker instance.
