# Custom Block

Custom blocks are parsed by the shared MDX compiler. Each authored directive name becomes an independent CSS class and `data-type`; no predefined variants or icons are required.

## Live Markdown previews

::: warning Handle Missing Options

The `options` parameter is optional. **Provide default values** when comparing screenshots.

```ts
myCustomComparator: (
  reference,
  actual,
  { createDiff, threshold = 0.1, maxDiff = 100 },
) => {
  // Comparison logic
}
```

:::

::: experimental Experimental Feature

Any new type works without registering it in the parser. Its presentation comes from consumer CSS.

## Authoring syntax

```md
::: arbitrary Custom title

Normal **Markdown** content and fenced code blocks.

:::
```

The compiler emits `class="custom-block arbitrary"` with `data-type="arbitrary"`, preserving any nested blocks and child markup.

## Styling

Override CSS custom properties in the consuming application instead of hardcoding type-specific variants in the compiler:

```css
.custom-block.demo-variant {
  --custom-block-border-color: rebeccapurple;
  --custom-block-background: color-mix(in srgb, rebeccapurple 8%, transparent);
}
```
