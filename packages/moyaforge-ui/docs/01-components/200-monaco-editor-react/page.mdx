# Monaco Editor React

`MonacoEditorWorkspace` provides file tabs, editor content, Save, and Copy controls.
The setup below is for an existing **Vite + React + TypeScript** app using React Monaco.
Complete the configuration and startup steps before mounting the editor.

## Install dependencies

From your Vite project directory:

```sh
npm install @moyarich/moyaforge-ui @moyarich/moyaforge-monaco @monaco-editor/react monaco-editor lucide-react
npm install -D vite @vitejs/plugin-react typescript @types/node @types/react @types/react-dom csstype
```

The Vite plugin reads `@types/react`, `@types/react-dom`, and `csstype` from this
project to provide type checking inside Monaco. They must be installed locally.

## Configure Vite

Use this complete `vite.config.ts` at the project root. If you already have a
configuration, add `monacoReactTypesPlugin` to its existing `plugins` array.

```ts filename="vite.config.ts"
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import { monacoReactTypesPlugin } from "@moyarich/moyaforge-monaco/vite";

export default defineConfig({
  plugins: [react(), monacoReactTypesPlugin(import.meta.dirname)],
});
```

`import.meta.dirname` points at the directory containing `vite.config.ts` and
`package.json`. The plugin supplies the React declarations; Vite’s built-in
`?worker` handling bundles the worker scripts used by the runtime.

## Configure TypeScript

Keep your Vite React template’s existing TypeScript settings. In
`tsconfig.json`, add the virtual-module types to `compilerOptions.types`:
This is a settings fragment to merge, not a replacement for your entire tsconfig.

```json filename="tsconfig.json"
{
  "compilerOptions": {
    "types": ["vite/client", "@moyarich/moyaforge-monaco/virtual"]
  }
}
```

## Initialize workers

Configure workers once in `src/main.tsx`, before rendering your app. This keeps
Monaco and its workers local to your application.

Worker setup runs at startup,
not inside an editor component or a React effect.

```tsx filename="src/main.tsx"
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import { configureReactWorkers } from "@moyarich/moyaforge-monaco/react";
import App from "./App";

configureReactWorkers();

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <App />
  </StrictMode>,
);
```

## Usage

Create `src/App.tsx` with the example below. `onFileChange` updates the files in
React state, keeping your edits when you switch tabs. Selecting **Save** calls
`onSave` with the active file’s name and current contents. This example displays
a confirmation message; to save changes permanently, use that callback to write
to your storage or send the file to your API.

```tsx filename="src/App.tsx"
import { useState } from "react";
import { MonacoEditorWorkspace } from "@moyarich/moyaforge-ui/components/MonacoEditorWorkspace";

export default function App() {
  const [files, setFiles] = useState([
    {
      name: "App.tsx",
      value: `export default function App() {
  return <h1>Hello!</h1>;
}
`,
    },
    {
      name: "styles.css",
      value: `h1 { color: royalblue; }
`,
    },
    { name: "index.ts", value: "const answer = 42;" },
  ]);
  const [message, setMessage] = useState("");

  function updateFile(name: string, value: string) {
    setFiles((current) =>
      current.map((file) => (file.name === name ? { ...file, value } : file)),
    );
  }

  function onSaveHandler(name: string, value: string) {
    setMessage(`${name}: received ${value.length} characters.`);
  }

  return (
    <>
      <MonacoEditorWorkspace
        files={files}
        onFileChange={updateFile}
        onSave={onSaveHandler}
        height={320}
      />
      <p role="status">{message || "Edit a file, then select Save."}</p>
    </>
  );
}
```

Run `npm run dev` and open the Vite URL. The workspace renders the supplied
source as editable text. It does not execute the edited application; use
[PreviewCodeEditor](/ui/components/preview-code-editor) for a live rendered preview.

## Copy component source instead

If you prefer editable component files in your project, use one of these commands
instead of importing `MonacoEditorWorkspace` from the UI package:

```sh
npx @moyarich/moyaforge-cli@latest add monaco-editor-workspace
```

```sh
npx shadcn@latest add moyarich/moyaforge/monaco-editor-workspace
```

Then import from the generated component location, such as
`@/components/ui/MonacoEditorWorkspace`. The Vite plugin, type packages, and worker
initialization above are still required.

## Using React Monaco and TypeFox together

Keep the same Vite plugin, but replace the standalone initializer in `main.tsx`:

```ts filename="main.tsx"
import { initializeSharedMonaco } from "@moyarich/moyaforge-monaco/shared";

await initializeSharedMonaco();
```

Call it before `createRoot(...).render(...)`, and remove `configureReactWorkers()`.
Use one initialization strategy per application. See
[Monaco runtime](../../../../../docs/04-development/30-monaco-runtime/page.mdx)
for the TypeFox dependencies and shared-runtime setup.

## Styling

Create `editor.css` **in your application**, import it into your React component, and pass a scoped class to `MonacoEditorWorkspace`:

```tsx
import { MonacoEditorWorkspace } from "@moyarich/moyaforge-ui/components/MonacoEditorWorkspace";
import "./editor.css";

<MonacoEditorWorkspace
  className="react-monaco-editor"
  files={files}
  height={320}
/>;
```

```css
/* editor.css — user-owned, not a MoyaForge internal stylesheet */
.react-monaco-editor {
  --mf-editor-border: #cbd5e1;
  --mf-editor-toolbar-background: #f1f5f9;
  --mf-editor-surface: #fff;
  --mf-tabs-accent: #2563eb;
  --mf-tabs-indicator-size: 3px;
  --mf-tabs-active-color: #1d4ed8;
}
```

You can also set `--mf-tabs-corner-size`, `--mf-tabs-active-background`, and `--mf-tabs-radius` to customize the tab shape and panel surface. The CSS variables style the **editor UI**, not the underlying Monaco syntax theme. See [Editor Workspace](/ui/components/editor-workspace) for an editable, stateful example and curved-tab CSS preset.

<summary>Advanced options</summary>

- `activeFile` and `onActiveFileChange` control the selected file.
- `theme` overrides the inherited light/dark appearance.
- `options`, `beforeMount`, and `onMount` customize Monaco.
- `showCopyButton`, `showBreadcrumbs`, `tools`, and `renderBreadcrumbs` customize the UI-owned workspace.
- `className` and `--mf-tabs-*` / `--mf-editor-*` CSS variables customize the UI.

For an editor without tabs or toolbar, import `MonacoEditorReact` from
`@moyarich/moyaforge-monaco/components/MonacoEditorReact`.
