# Monaco Editor React

`MonacoEditorPanel` provides file tabs, editor content, Save, and Copy controls.
It uses the standalone `monaco-editor` runtime when this is the only editor integration in the app.

## Install the panel

Start with an existing Vite + React + TypeScript app and choose an install method.

## Install dependencies

Install the runtime and worker dependencies for any of the three methods.

```sh
npm install @moyarich/moyaforge-monaco @monaco-editor/react 'monaco-editor@^0.52.0' 'lucide-react@^1.56.0'
npm install -D @types/react @types/react-dom csstype
```

The examples below use the npm import. For a source install, import
`MonacoEditorPanel` from `./components/ui/MonacoEditorPanel/index.js`
in `src/App.tsx`, or use the directory configured by your installer.

## Configure Vite

Add `monacoReactTypesPlugin` to the plugins in your existing `vite.config.ts`.
Pass the project directory so it can resolve React, React DOM, and `csstype`
declarations for the editor's TypeScript worker.

```ts filename="vite.config.ts"
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import { monacoReactTypesPlugin } from "@moyarich/moyaforge-monaco/vite/monacoReactTypesPlugin";

export default defineConfig({
  plugins: [react(), monacoReactTypesPlugin(import.meta.dirname)],
});
```

## Configure TypeScript

Add `@moyarich/moyaforge-monaco/vite/react-types` to
`compilerOptions.types` in the TypeScript config that covers your app.
Keep the other entries already in the list.

```json filename="tsconfig.json"
{
  "compilerOptions": {
    "types": ["vite/client", "@moyarich/moyaforge-monaco/vite/react-types"]
  }
}
```

## Initialize workers

For React Monaco on its own, call `configureReactWorkers()` in `src/main.tsx` before rendering the app. Vite bundles the editor workers with your application.

```tsx filename="src/main.tsx"
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import { configureReactWorkers } from "@moyarich/moyaforge-monaco/workers/configureReactWorkers";
import App from "./App";

configureReactWorkers();

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <App />
  </StrictMode>,
);
```

## Usage

Create `src/App.tsx` with the example below. `onFileChange` updates the files in
React state, keeping your edits when you switch tabs. Selecting **Save** calls
`onSave` with the active file’s name and current contents. This example displays
a confirmation message. To save changes permanently, use that callback to write
to your storage or send the file to your API.

```tsx filename="src/App.tsx"
import { useState } from "react";
import { MonacoEditorPanel } from "@moyarich/moyaforge-ui/components/MonacoEditorPanel";

export default function App() {
  const [files, setFiles] = useState([
    {
      name: "App.tsx",
      value: `export default function App() {
  return <h1>Hello!</h1>;
}
`,
    },
    {
      name: "styles.css",
      value: `h1 { color: royalblue; }
`,
    },
    { name: "index.ts", value: "const answer = 42;" },
  ]);
  const [message, setMessage] = useState("");

  function updateFile(name: string, value: string) {
    setFiles((current) =>
      current.map((file) => (file.name === name ? { ...file, value } : file)),
    );
  }

  function onSaveHandler(name: string, value: string) {
    setMessage(`${name}: received ${value.length} characters.`);
  }

  return (
    <>
      <MonacoEditorPanel
        files={files}
        onFileChange={updateFile}
        onSave={onSaveHandler}
        height={320}
      />
      <p role="status">{message || "Edit a file, then select Save."}</p>
    </>
  );
}
```

Run `npm run dev` and open the Vite URL. The panel renders the supplied
source as editable text. To run the edited application, use
[PreviewCodeEditor](/ui/components/preview-code-editor) for a live rendered preview.

## Using React Monaco and TypeFox together

For an application using both editors, use the shared initializer as your one startup call in `main.tsx`.

```ts filename="main.tsx"
import { initializeMonacoVscodeRuntime } from "@moyarich/moyaforge-monaco/runtime/initializeMonacoVscodeRuntime";

await initializeMonacoVscodeRuntime();
```

Call it before `createRoot(...).render(...)`.
Use one initialization strategy per application. See
[Monaco runtime](../../../../../docs/04-development/30-monaco-runtime/page.mdx)
for the TypeFox dependencies and shared-runtime setup.

## Styling

Create `editor.css` **in your application**, import it into your React component, and pass a scoped class to `MonacoEditorPanel`:

```tsx
import { MonacoEditorPanel } from "@moyarich/moyaforge-ui/components/MonacoEditorPanel";
import "./editor.css";

<MonacoEditorPanel
  className="react-monaco-editor"
  files={files}
  height={320}
/>;
```

```css
.react-monaco-editor {
  --mf-editor-border: #cbd5e1;
  --mf-editor-toolbar-background: #f1f5f9;
  --mf-editor-surface: #fff;
  --mf-tabs-accent: #2563eb;
  --mf-tabs-indicator-size: 3px;
  --mf-tabs-active-color: #1d4ed8;
}
```

You can also set `--mf-tabs-corner-size`, `--mf-tabs-active-background`, and `--mf-tabs-radius` to customize the tab shape and panel surface. Use the panel’s `theme` prop to change Monaco’s syntax theme. See [Editor Panel](/ui/components/editor-panel) for an editable, stateful example and curved-tab CSS preset.

<details>
<summary>Advanced options</summary>

- `activeFile` and `onActiveFileChange` control the selected file.
- `theme` overrides the inherited light/dark appearance.
- `options`, `beforeMount`, and `onMount` customize Monaco.
- `showCopyButton`, `showBreadcrumbs`, `tools`, and `renderBreadcrumbs` customize the UI-owned panel.
- `className` and `--mf-tabs-*` / `--mf-editor-*` CSS variables customize the UI.

For an editor without tabs or toolbar, import `MonacoEditorReact` from
`@moyarich/moyaforge-monaco/components/MonacoEditorReact`.
