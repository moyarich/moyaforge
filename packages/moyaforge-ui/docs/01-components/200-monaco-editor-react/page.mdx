# Monaco Editor React

import { MonacoEditorWorkspace } from "@moyarich/moyaforge-ui/components/MonacoEditorWorkspace";

The Monaco editing runtime is provided by `moyaforge-monaco`; tabs, actions and editor layout are provided by `moyaforge-ui`.

## Installation

<CodeGroup label="Install Monaco Editor React">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add monaco-editor-react
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/monaco-editor-react
```

</CodeTab>
</CodeGroup>

In an existing React app, ensure these runtime dependencies are installed:

```sh
npm install @moyarich/moyaforge-ui @moyarich/moyaforge-monaco @monaco-editor/react monaco-editor lucide-react
```

For Vite, register `monacoReactTypesPlugin(import.meta.dirname)` from `@moyarich/moyaforge-monaco/vite` in `vite.config.ts` and call `configureReactWorkers()` from `@moyarich/moyaforge-monaco/react` once at application startup. If using TypeFox too, call `initializeSharedMonaco()` from `/shared` instead. Other bundlers need their own worker setup.

For editor worker architecture and shared initialization details, see [Monaco runtime](../../../../../docs/04-development/30-monaco-runtime/page.mdx).

The editor setup belongs in your application's `main.tsx`, **not** inside the component. For standalone React Monaco applications:

```ts
import { configureReactWorkers } from "@moyarich/moyaforge-monaco/react";

configureReactWorkers();
```

## Usage

::: code-preview Editable TypeScript workspace

<LiveMonacoEditorReact
  files={[{ name: "index.ts", value: "const answer = 42;" }]}
  height={320}
/>

:::

The interactive workspace comes from `moyaforge-ui`; the headless runtime remains available from `moyaforge-monaco` for custom shells.

```tsx
import { MonacoEditorWorkspace } from "@moyarich/moyaforge-ui/components/MonacoEditorWorkspace";

<MonacoEditorWorkspace
  files={[
    { name: "index.ts", value: "const answer = 42;" },
    { name: "styles.css", value: "body { margin: 0; }" },
  ]}
  height={320}
/>;
```

The UI workspace owns tabs, Save, and Copy actions. Keep files in React state via `onFileChange`; `onSave` receives the active file's latest value.

<details>
<summary>Advanced options</summary>

- `activeFile` and `onActiveFileChange` control the selected file.
- `theme` overrides the inherited light/dark appearance.
- `options`, `beforeMount`, and `onMount` customize Monaco.
- `showCopyButton`, `showBreadcrumbs`, `tools`, and `renderBreadcrumbs` customize the UI-owned workspace.
- `className` and `--mf-tabs-*` / `--mf-editor-*` CSS variables customize the UI.

The installed `components/MonacoEditorReact/README.md` includes additional dependency and setup guidance.

</details>

## Styling

Customize the workspace using `className`, `--mf-tabs-*`, and `--mf-editor-*` CSS variables. The underlying Monaco runtime is UI-free.
