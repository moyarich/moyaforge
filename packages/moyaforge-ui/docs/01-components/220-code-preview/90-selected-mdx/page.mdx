# MDX with an inline component

Open **Code** and copy **selected-mdx-usage.mdx** for the full directive and all of its inline files.

An MDX entry can combine prose, directives, and an imported component from another named fence. It uses the host's configured remark and rehype plugins.

::::::code-preview[Release note]{preview="release.mdx,release.css"}

`release.mdx` is the rendered entry. `ReleaseBadge.tsx` supplies its component, while `release.css` styles the preview. Neither the entry nor its component needs a separate file on disk. This example requires the Vite code-preview plugin and the site's custom-block directive mapping.
