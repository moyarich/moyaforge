# Markdown with inline CSS

Open **Code** and copy **selected-markdown-usage.mdx** for the full directive and all of its inline files.

Select named fences with `preview`. Markdown runs through the site's configured remark plugins, CSS is scoped to this preview, and shell commands render as code blocks. All selected and unselected named fences remain available in **Code**.

::::::code-preview[Before you continue]{preview="notice.md,notice.css,install.sh"}

````mdx filename="selected-markdown-usage.mdx"
:::::code-preview[Before you continue]{preview="notice.md,notice.css,install.sh"}

```md filename="notice.md"
::: warning Before you continue

Save a **backup** before updating your project.

- Export your configuration.
- Keep the backup somewhere safe.

:::
```

```css filename="notice.css"
.custom-block.warning {
  --mf-custom-block-border: #b45309;
  --mf-custom-block-bg: color-mix(in srgb, #b45309 10%, transparent);
}
```

```sh filename="install.sh"
npm install
```
````
