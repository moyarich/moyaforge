# CodePreview

Use `:::code-preview` to show a live example and its source files.

## Installation

## Inline MDX preview

Save this as `example.md` in a docs site with the mapping below. The
directive renders the greeting and shows its source when you select **Code**.

```md filename="example.md"
:::code-preview[Greeting]

**Hello** from `Markdown`.

:::
```

Add the following mapping to `createMdxOptions` and register
`InlineCodePreview` from `@moyarich/moyaforge-ui/components/CodePreview` in
your MDX provider. Write the example once inside the directive. MDX renders the
body in the preview and shows the authored Markdown and JSX in the **Code** tab.

```ts
createMdxOptions({
  componentMappings: {
    "code-preview": {
      component: "InlineCodePreview",
      titleProp: "title",
      sourceProp: "code",
      filesProp: "sourceFiles",
    },
  },
});
```

Use a unique `filename="..."` on each top-level fence to add a source tab.
Import any stylesheet you want to apply to the live preview.

## File-backed previews with Vite

Register your docs directory first. This registry discovers Markdown and MDX pages under `docs/`.

```ts filename="registry.config.ts"
import type { RegistryConfiguration } from "@moyarich/moyaforge-mdx/vite";

export default {
  sources: {
    docs: {
      base: "docs",
      include: ["**/*.md", "**/*.mdx"],
      pageFiles: "all",
      navigation: { label: "Docs" },
    },
  },
} satisfies RegistryConfiguration;
```

Add the preview plugin to your Vite config after discovering the content registry. The CLI playground template already includes this setup.

```ts
import {
  createCodePreview,
  createCodePreviewPlugin,
  resolveCodePreviewSource,
} from "@moyarich/moyaforge-mdx/vite";

import { createContentDiscovery } from "@moyarich/moyaforge-mdx";
import registry from "./registry.config.js";

const contentRoot = import.meta.dirname;
const discovery = createContentDiscovery(registry, contentRoot);
const { registry: discovered } = await discovery.get();
const codePreview = createCodePreview({
  root: contentRoot,
  sources: registry.sources,
  pages: discovered.pages,
});
```

Add `createCodePreviewPlugin(codePreview)` to Vite’s `plugins` array. Extend the
`code-preview` mapping above with these options.

```ts
localSources: true,
resolveCodePreviewExample: (reference, authoredFile) =>
  resolveCodePreviewSource({ context: codePreview, reference, authoredFile }),
```

In your MDX provider, use the loader map from
`virtual:moyaforge-mdx/code-preview-components` to render the component selected
by the directive. The plugin also exposes
`virtual:moyaforge-mdx/code-preview-sources` for lazy raw-source imports.
The nested source directive supplies the files shown in the Code view.

```md
::::code-preview[Greeting]{example="./Greeting.tsx"}

::code-preview-sources{files="./Greeting.tsx,./styles.css" replacements="portable"}

::::
```

The referenced React component should be a sibling `.tsx` or `.jsx` file with a
default export. This syntax works in plain Markdown pages.

## Styling

Set `--mf-preview-border`, `--mf-preview-radius`, or `--mf-preview-padding` on a containing element to style the preview frame.

For a custom toolbar or source panel, use the individual [Preview slots](/ui/components/preview) and install them with `add preview`.
