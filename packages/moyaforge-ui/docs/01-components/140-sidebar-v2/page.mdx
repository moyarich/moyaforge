# Sidebar V2

This example uses the real source-owned MoyaForge UI component. It does not create a second component implementation or application router.

## Installation

<CodeGroup label="Install Sidebar V2">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add sidebar-v2
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/sidebar-v2
```

</CodeTab>
</CodeGroup>

Install `sidebar-v2` from the MoyaForge registry to copy the selected component source and CSS into your application.

[All UI components](/ui)

## Usage

The examples use `@/` as an alias for `src/`. Use a relative import if your app has no alias configured.

```tsx
import { SidebarSection } from "@/components/ui/SidebarV2/SidebarSection";

import { SidebarItem } from "@/components/ui/SidebarV2/SidebarItem";

import { SidebarHeader } from "@/components/ui/SidebarV2/SidebarHeader";

import { SidebarGroup } from "@/components/ui/SidebarV2/SidebarGroup";

import { SidebarFooter } from "@/components/ui/SidebarV2/SidebarFooter";

import { SidebarContent } from "@/components/ui/SidebarV2/SidebarContent";

import { Sidebar } from "@/components/ui/SidebarV2/Sidebar";

<Sidebar aria-label="Sample navigation">
  <SidebarHeader>Documentation</SidebarHeader>
  <SidebarContent>
    <SidebarSection>
      <SidebarGroup label="Getting started">
        <SidebarItem>Overview</SidebarItem>
        <SidebarItem>Components</SidebarItem>
      </SidebarGroup>
    </SidebarSection>
  </SidebarContent>
  <SidebarFooter>Component registry</SidebarFooter>
</Sidebar>;
```

## Styling

Set `--sidebar-background` and `--sidebar-color` on the sidebar, and use `--sidebar-padding` and `--sidebar-gap` to adjust spacing.
