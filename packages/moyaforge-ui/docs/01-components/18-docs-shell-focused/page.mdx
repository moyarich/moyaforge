# Docs Shell Focused

Use `header={null}` or `navigation={null}` to suppress those slots. Omit a prop to use its default.

## Live preview

<DocsShellFocused
  title="Focused reading"
  subtitle="A distraction-free documentation layout"
  header={<strong>Focused shell preview</strong>}
  navigation={null}
>
  <p>Reading content with independently replaceable slots.</p>
</DocsShellFocused>

## Usage

```tsx
<DocsShellFocused
  title="Focused reading"
  subtitle="A distraction-free documentation layout"
  header={<strong>Focused shell preview</strong>}
  navigation={null}
>
  <p>Reading content with independently replaceable slots.</p>
</DocsShellFocused>
```

## Installation

Install `docs-shell-focused` from the MoyaForge component registry to obtain editable source and related styles. UI remains separate from the headless framework package.
