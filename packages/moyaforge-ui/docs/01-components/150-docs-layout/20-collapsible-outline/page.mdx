# Docs Layout · Collapsible outline

Set `toc.collapsible` to enable native HTML `<details>` disclosure, and
`toc.defaultOpen` to control its initial state. No React disclosure state or
JavaScript click handler is required. Custom `outline` and `sidebar` slots
continue to replace the defaults.
