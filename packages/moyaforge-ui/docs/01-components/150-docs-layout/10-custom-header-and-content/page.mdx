# Docs Layout · Custom header and content

Select **Guide** or **Release notes** in the custom header. The example changes
its article and footer while keeping the same layout, without leaving this page.

Pass your own React content to `header` and `footer`, and render the article as
children. `sidebar={null}` and `outline={null}` remove those optional regions.
The example’s CSS styles the supplied content and contains the full-page shell
inside the preview.
