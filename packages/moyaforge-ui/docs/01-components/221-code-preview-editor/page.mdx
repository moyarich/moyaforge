# CodePreviewEditor

Use `CodePreviewEditor` to show a live React preview beside editable Monaco source files. It owns the file state and reset action; your `renderPreview` callback decides how edited files become a preview.

## Installation

<CodeGroup label="Install CodePreviewEditor">
<CodeTab label="MoyaForge CLI">

```sh
npx @moyarich/moyaforge-cli@latest add code-preview-editor
```

</CodeTab>
<CodeTab label="shadcn">

```sh
npx shadcn@latest add moyarich/moyaforge/code-preview-editor
```

</CodeTab>
</CodeGroup>

The registry item installs the Preview source files and depends on
`@moyarich/moyaforge-monaco` for the editor. Install
`@monaco-editor/react` and `monaco-editor` and configure workers for
your bundler before rendering the editor. Other MoyaForge UI components
do not require Monaco.

## Usage

Pass the editable files and a renderer that consumes their current values:

```tsx
<CodePreviewEditor
  title="Counter"
  files={[{ name: "Counter.tsx", language: "typescript", value: source }]}
  renderPreview={(files) => <Counter source={files[0]?.value ?? ""} />}
/>
```

Provide `usageSource` when the Code view should include a read-only tab with the integration code. The editor displays that snippet first and uses it for the Preview copy action.

## Styling

The component uses the Preview frame tokens, including `--mf-preview-padding`, and the Monaco editor tokens documented in [Monaco Editor React](/ui/components/monaco-editor-react).
