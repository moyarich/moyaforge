# UI Components

These examples use the canonical source in `packages/moyaforge-ui/src/components/`.
Components are installed individually through the MoyaForge component registry;
they are not bundled into the framework package.

## Component demonstrations

- [Code Block](/ui/components/code-block) — live MDX code blocks with copy actions.
- [Code Group](/ui/components/code-group) — interactive command tabs.
- [Copy Button](/ui/components/copy-button) — clipboard feedback.
- [Source](/ui/components/source) — source rendering.
- [Demo](/ui/components/demo) — composable previews.
- [Empty State](/ui/components/empty-state) — informative empty views.
- [Page](/ui/components/page) — semantic content wrapper.
- [Edit Page Link](/ui/components/edit-page-link) — repository edit links.
- [Navigation Tree](/ui/components/navigation-tree) — nested documentation navigation.
- [Search](/ui/components/search) — searchable input primitive.
- [Doc Outline](/ui/components/doc-outline) — scroll-aware heading navigation.
- [Table of Contents](/ui/components/table-of-contents) — heading links.
- [Sidebar V1](/ui/components/sidebar-v1) — page-driven navigation.
- [Sidebar V2](/ui/components/sidebar-v2) — composable sidebar primitives.
- [Docs Layout](/ui/components/docs-layout) — slot-based documentation layout.
- [Documentation Site](/ui/components/documentation-site) — standalone documentation chrome.

More components will be added here using the same pattern. Every page is discovered
from this directory by the playground's MDX registry, without manually creating routes.
