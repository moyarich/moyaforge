# Changelog

## 0.1.0

- Introduce the standalone `moyaforge` executable and public npm package.
- Install canonical GitHub registry components with dependency resolution, custom
  destinations, dry runs, text diffs, and explicit overwrite handling.
- Scaffold source-owned/package-managed docs, hybrid, and isolated existing-app
  starters using the shared MDX/Vite, router, and optional SQLite APIs.
