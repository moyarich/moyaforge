# `moyaforge list`

List available registry items to find names you can pass to `add`.

```sh
npx @moyarich/moyaforge-cli@latest list
```

Use `--cwd <path>` to read settings from another project or `--registry <source>` to list items from a different registry.

## Install an item you find

Use the registry item name printed by `list`:

```sh
npx @moyarich/moyaforge-cli@latest list
npx @moyarich/moyaforge-cli@latest add preview-code
```

## Use a custom registry

Pass the same registry to both commands:

```sh
npx @moyarich/moyaforge-cli@latest list --registry ./registry.json
npx @moyarich/moyaforge-cli@latest add code-block --registry ./registry.json
```

To reuse that registry for future commands, save it with `init --registry ./registry.json`. The registry can also be a directory or a URL pointing to `registry.json`.
