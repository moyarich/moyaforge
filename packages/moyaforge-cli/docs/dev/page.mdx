# `moyaforge dev`

Start your project’s Vite development server. Open the URL printed in the terminal.

```sh
npx @moyarich/moyaforge-cli@latest dev --port 5173
```

Run this from a project with Vite installed, or pass `--cwd <path>` to select the project directory. Other flags are passed to Vite.
