# `moyaforge preview`

Serve your production build locally to check it before deploying. Run the build command first.

```sh
npx @moyarich/moyaforge-cli@latest preview --port 4173
```

Run this from a project with Vite installed, or pass `--cwd <path>` to select the project directory. Other flags are passed to Vite.
