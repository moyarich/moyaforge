# MoyaForge CLI

Use the CLI to create a React/Vite documentation site or copy editable UI components into an existing React project. You need Node.js 24.11+ and npm. The examples use `npx`, so you can run them without a global installation.

## Create your first site

Run these commands from the folder where you keep your projects:

```sh
mkdir my-docs
cd my-docs
npx @moyarich/moyaforge-cli@latest init --template playground
npm run dev
```

`init` generates the application and installs its dependencies. Open the local URL printed by Vite. Edit `docs/page.mdx` to change the landing page, then save to see the result in your browser.

The playground template includes navigation, code previews, syntax highlighting, and starter documentation. Add `--search` to the `init` command to enable SQLite search.

### Find your files

| File or directory           | What to change                                        |
| --------------------------- | ----------------------------------------------------- |
| `docs/`                     | Write documentation in Markdown or MDX.               |
| `registry.config.ts`        | Configure the site's content sources.                 |
| `src/mdx-provider.tsx`      | Register components used by your MDX pages.           |
| `src/components/ui/`        | Customize installed UI component source and CSS.      |
| `moyaforge.components.json` | Configure the CLI registry and component destination. |
| `vite.config.ts`            | Configure the development server and content plugins. |

Before publishing, check and build the site:

```sh
npm run typecheck
npm run build
npm run preview
```

The production output is in `dist/`. `preview` lets you inspect that build locally.

## Add components to an existing React app

Run these commands in the folder containing your application's `package.json`:

```sh
npx @moyarich/moyaforge-cli@latest init
npx @moyarich/moyaforge-cli@latest list
npx @moyarich/moyaforge-cli@latest add copy-button
```

Plain `init` creates the CLI configuration. `add` copies the selected component and its required component files into `src/components/ui/`, then installs its npm dependencies.

For example, use the installed button in `src/App.tsx`:

```tsx
import { CopyButton } from "./components/ui/CopyButton/CopyButton.js";

export default function App() {
  return <CopyButton value="npm install">Copy command</CopyButton>;
}
```

The component imports its own CSS. You own the installed files and can edit them directly.
