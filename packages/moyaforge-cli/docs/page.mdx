# MoyaForge CLI

`@moyarich/moyaforge-cli` provides the `moyaforge` executable for generating documentation projects and installing UI component source. It requires Node.js 24.11+ and npm.

```sh
npx @moyarich/moyaforge-cli@latest init --template docs
npm run dev
```

## Commands

- [`init`](/packages/moyaforge-cli/docs/init) Configure components or scaffold a documentation project.
- [`list`](/packages/moyaforge-cli/docs/list) Browse available registry items.
- [`add`](/packages/moyaforge-cli/docs/add) Install editable components.
- [`dev`](/packages/moyaforge-cli/docs/dev) Start the local development server.
- [`preview`](/packages/moyaforge-cli/docs/preview) Serve a production build locally.
