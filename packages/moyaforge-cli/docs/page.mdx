# MoyaForge CLI

`@moyarich/moyaforge-cli` provides the `moyaforge` executable for generating documentation projects and installing UI component source. It requires Node.js 24.11+ and npm.

```sh
npx @moyarich/moyaforge-cli@latest create
npm run dev
```

## Commands

- [`create`](/packages/moyaforge-cli/docs/create) Scaffold a documentation project.
- [`init`](/packages/moyaforge-cli/docs/components/init) Save component registry settings.
- [`list`](/packages/moyaforge-cli/docs/components/list) Browse available registry items.
- [`add`](/packages/moyaforge-cli/docs/components/add) Install editable components.
- [`dev`](/packages/moyaforge-cli/docs/dev) Start the local development server.
- [`preview`](/packages/moyaforge-cli/docs/preview) Serve a production build locally.
