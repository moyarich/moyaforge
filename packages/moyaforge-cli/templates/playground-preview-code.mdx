## Code preview

Select **Code** to see the live markup and the named source file.

::: preview-code Greeting

<p><strong>Hello from the playground.</strong></p>

```ts filename="greeting.ts"
export const greeting = "Hello from the playground.";
```

:::

### Render a TSX example with shared CSS

Select a named TSX fence to render its default export. Named CSS and TypeScript fences can be imported by that module; all named files appear in the Code view.

:::preview-code[Inline React greeting]{preview="Example.tsx" refresh}

```tsx filename="Example.tsx"
import Greeting from "./Greeting.tsx";
import { message } from "./message.ts";
import "./example.css";

export default function Example() {
  return (
    <div className="starter-preview-greeting">
      <Greeting />
      <p>{message}</p>
    </div>
  );
}
```

```ts filename="message.ts"
export const message: string = "Hello from a React component.";
```

```css filename="example.css"
.starter-preview-greeting {
  padding: 1rem;
  border: 1px solid currentColor;
  border-radius: 0.5rem;
}
```

:::

### Preview a React component from a file

The `component` attribute imports the registered `Greeting.tsx` at build time. The `preview-code-sources` directive lists the files shown in the Code view. This works in plain Markdown pages too.

::::preview-code[Greeting component]{component="./Greeting.tsx"}

::preview-code-sources{files="./Greeting.tsx"}

::::

### Preview source code without rendering it

Use `code` when you want to display a file as highlighted source without loading it as a React component.
