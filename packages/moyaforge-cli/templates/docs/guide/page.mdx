# Guide

Your generated documentation is ready to edit. Pages are discovered from
the `docs/` folder, so you can add Markdown or MDX without editing the router.

## Add a page

Create a directory containing a `page.mdx` file, then add a title:

```mdx
---
title: My new page
---

# My new page
```

## Customize components

See [Components](/docs/components) for code blocks, tabs, and custom callouts.
Return to [Welcome](/docs) to review your installation instructions.
